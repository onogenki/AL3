# 11月分進捗
## 操作方法
タイトル画面でspaceボタンでゲーム画面。
ADで移動。Wでジャンプ。
ゲーム画面で1ボタンを押すとタイトル画面に戻る。
## 今月の成果一覧
- 壁判定
 壁判定はできていたが位置がおかしく、空中で地面判定などが発生していた。
ブロックやplayerのブレンダー側の位置がおかしかったため調整して修正。
- カメラ調整
  playerを追いかけるカメラを制作。playerを追従しすぎて気持ち悪い揺れなどを調整して
快適に遊べるようにしました。
playerより左側にある壁が見えなかったのがgameScene.cppで上書きされてたのが原因だったのでgameSceneを見直しカメラの範囲を修正した。
- シーン切り替え
 タイトル画面とゲーム画面に切り替えて、初期化、生成もしっかり制作。
